# scripts/eyeball-surfaces.txt - THE SURFACE MAP (eyeball-pack, card t_214ca1bd).
#
# One line per webui surface:
#
#   <surface>|<component-path-globs>|<how-to-reach>
#
# surface   slug used in the pack's file names: <out-dir>/<n>-<surface>.png
# globs     comma-separated repo-relative git-path globs, NO spaces
#           (`*` crosses `/`, so `webui/app/components/chat/*` is the whole
#           directory); a changed file that fits any surface's globs lists
#           that surface in the pack
# reach     semicolon-separated steps, run in order against the lane:
#             url:<path>       open <lane-url><path>
#             reload           reload the page
#             vp:<w>x<h>       set the viewport
#             press:<key>      press a key (Control+k, Escape, ...)
#             tab:<Name>       click the dock tab whose name matches exactly
#                              (aria-label, title, or .dock-tab-title text -
#                              edge strips are icon-only chips)
#             click:<selector> document.querySelector(sel).click()
#             eval:<js>        run JS (a throw fails the step)
#             wait:<js>        poll a BOOLEAN js expression until true (bounded
#                              by EYEBALL_REACH_TIMEOUT); a `?1:0` probe never
#                              matches - return !!x instead
#             waittext:<text>  wait for text to render
#
# A surface no changed component maps to is skipped ("no changed
# components"). A reach that fails on the lane skips THAT surface with the
# reason printed - a missing seed or a disabled capsule must not cost the
# whole pack. No line may contain `|` beyond its two separators (the reach
# spec's own steps are `;`-separated for exactly that reason).
#
# Routes verified against webui/app (app.vue's route table: /, /chat/<id>,
# /board, /settings) and the dock registry (webui/app/composables/dockables.ts
# titles: Sessions, chat, viewer, Files, cron, skills, tools, Agents,
# Settings, kanban, Insights, MCP, Terminal, Logs, Browser, Notifications).
